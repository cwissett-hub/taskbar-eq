Oscilloscope — phosphor colourways

Same renderer throughout: graticule, glowing trace, genuine persistence trails. Only the phosphor changes — and with it the decay rate, because real phosphors differ in how long they hold.

Analogue VU — dial backlight colourways

Same twin-needle movement and ~300ms ballistics throughout. The backlight changes the face tint, the printed ink, the needle and the glow pool. The overload arc stays red except on the red dial, where it goes white to stay legible.
